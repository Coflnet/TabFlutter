Spables für Excel

Diktierte Einträge aus der Spables-App erscheinen als neue Zeilen in einer Excel-Tabelle – in Excel für Windows/Mac, Excel im Web und in Arbeitsmappen auf SharePoint/OneDrive. Kein Konto nötig.

Add-in herunterladen (manifest.xml)

1. Add-in in Excel hinzufügen

  1. Excel öffnen, Arbeitsmappe öffnen.
  2. Start → Add-Ins → Weitere Add-Ins → Meine Add-Ins → Mein Add-In hochladen und die heruntergeladene Datei wählen.
  3. Auf der Registerkarte Start auf Spables klicken. Es erscheint ein Code.

Für das ganze Unternehmen: Microsoft 365 Admin Center → Einstellungen → Integrierte Apps → Benutzerdefinierte Apps hochladen → Link https://app.spables.app/excel/manifest.xml.

2. Handy verbinden

  1. Spables-App öffnen → Einstellungen → Integrationen (Excel) → Excel verbinden.
  2. Den Code aus Excel eingeben. Fertig.
Neue Einträge landen in der Tabelle „Spables“ auf dem Blatt „Spables“, solange die Arbeitsmappe mit dem Spables-Bereich geöffnet ist. Er öffnet sich mit der Arbeitsmappe automatisch. Ist Excel geschlossen, warten Einträge bis zu 30 Tage.

English

Download the manifest above, then in Excel: Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in. Click Spables on the Home tab to see a code and enter it in the Spables app under Settings → Integrations (Excel) → Connect Excel. Admins can deploy it company-wide via the Microsoft 365 admin center (Integrated apps) with the manifest URL.
